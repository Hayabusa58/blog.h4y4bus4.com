# 2025年を振り返って
12月中に今年の振り返り記事を出そうと思っていたのだが、気づけばギリギリに……
仕事・個人開発・プライベートの各カテゴリで印象深かったトピックをあげつつ今年を振り返ってみる。

## 仕事
### 開発タスクが増えた
昨年新卒で入社し、自社サービスの開発・運用エンジニアをしている。1年目の後半から開発現場で仕事するようになった
インフラの設計、レガシーなインフラの IaC 化、バックエンドAPI の改修、フロントエンド改修など、Webサービスの開発・運用に関してはかなり多彩な仕事をさせてもらっていると思う。
いまのところ、意向に沿った職務を適切な給与があると感じる。今後も順当に Web エンジニアとしてのスキルアップをしていきたい。

### 後輩の面倒をみるようになった
前述の通り私はまだ2年目だが、弊社では手を上げれば後輩の面倒を見る機会が与えられることがちょくちょくある。
そういう役回りをやる前は、自分自身もシステムに習熟しているわけではないのに、新人のサポートなんてできるか？と思っていたフシもあった。
ところが、実際にやってみるとオンボーディングのプロセスなど、自分がさいきん経験したからこそ助言できる部分はわりとあったし、何よりうまくサポートできてお礼を言われると素直に嬉しい。

### 情報処理安全確保支援士試験に合格した
IPA の秋期試験で情報処理安全確保支援士を受験し、合格した。
高校の頃から IT パスポート・基本情報処理技術者・応用情報処理技術者 と取得してきたが、今年ひとつの目標だった高度区分の試験に合格できてよかった。
IPA 試験はこれで一段落として、次はこれまで経験のないベンダ系の資格にチャレンジしてみようかと思っている。

## 個人開発、ホームラボ
### メイン環境を Linux に移行した
私用マシンの OS はこれまで一貫して Windows だったが、これをやめた。

理由としてはまず、そこそこ消費電力の多いグラフィックボードを積んだ Windows マシンを起動し続けるのは電気代の無駄だと思ったこと。
次に、仕事でネイティブの Linux 環境を常用するようになったので、プライベートもそれに合わせたほうが何かと都合が良さそうに思えたこと。

そんなわけで、今年のはじめに最低限のスペックで開発用のサブ機を自作し Linux を入れた。
電気代にかんしては、まぁトータルでみればそんなに得してなさそうだが、年末パーツが異常に値上がりしたのを見ると、結果的には先に作っていてよかったとなった。
デスクトップ環境はあまり深く考えず、Fedora + GNOME をチョイスした。
最初は Fedora + KDE Plasma を使っていたが、どうも自宅のデュアルモニターと相性が悪く、スリープしてもモニタの電源が切れないという不具合を踏んでしまった。
GNOME に切り替えたところ問題なく動いているので、とりあえずこれでええかという感じで使い続けている。

ただこれには若干後悔があり、なんとなく初期状態で高機能な Fedora は自分の使い方にあってない感じがしている。
Linux デスクトップを触るノウハウが溜まってきたので、つぎは Debian にしようかな……

### ホームラボのアップデート、個人開発のペースが上がった
不思議なことに学生の頃よりも時間がないはずだが、個人開発やホームラボの進捗ペースはあがった。
仕事で得た知識を個人開発に活かせるようになり、単位時間あたりの進捗量が増えるといういいサイクルができているように感じる。
これは、弊社の同僚に本格的なホームラボを立ち上げたり、爆速で個人開発を豊富な人が多く、刺激を受けている。

個人開発では Discord Bot を作ることが多かった。なんせ Discord がユーザインタフェースとして非常に便利。
ユーザとのやりとりが発生するソフトウェアのアーキテクチャを考えると、最初の候補として Discord を考えるくらい。

ただ、どうしても個人開発は 一発ネタ的な小規模なソフトウェアが多かった。
来年はそれなりに規模の大きなソフトウェアを完成させるという経験を積みたい。

## プライベート

### 推しが卒業した
時期的には年末の話題だが、ネガティブな話で締めたくないので最初に出しておく。
別記事でも触れたので
「推し」と認識していた存在が去る経験は初めてで、非常にショックが大きかった。ひとまずこの趣味は継続していくつもりではいるが、今後のあり方について考えさせられるきっかけになった。

### 終始、クルマで遊んでいた
趣味はもっぱらクルマと VTuber の追っかけをやっていた。特にクルマがコミュニケーションツールとして素晴らしく、色々なところで話題のきっかけとして活躍してくれた感がある。
思ったよりスポーツカー + MT はレアリティが高かったらしい。クルマつながりで話すようになった人もいるし、ありがたいことだ。

### 東北旅行に行った
夏頃、高校同期と3泊の東北旅行に行った。民泊を借りて BBQ したり料理したりした
お互い社会人になっても定期的に会ったり遊んだりバカ話ができる仲が続いているのはありがたいことである。お互いの属性が変わっても、学生時代に作ったコミュニティはより深いところでのつながりを感じて嬉しい。
今後も定期的に旅行に行きたい

### 大阪万博にいった
当初万博はあまり行くつもりがなかったのだがが、会社の同期に誘われて、生返事をしている間にいつのまにかチケットが確保されていた。行動力すごい
金曜夜に都内を出て、クルマで大阪まで移動、観光して1泊して帰宅という弾丸行程で、パビリオンに入れるか怪しい感じだったが、行ってみるとかなり楽しかった。
こういうイベントものはまずは行って雰囲気を味わうことが重要だと実感した。
なにより、誘ってくれるフットワークの軽い知人がいるのはとてもありがたい。

振り返ると2025年もいろいろあった年だった。
個人的にはそれなりになんとかやっていけたかと思っているので、来年もこの流れを続けられるようにしたい。。
